## 🧭 How to Explore

1. Clone this repository:
   ```bash
   git clone https://github.com/andybell/datascience-projects.git
   ```
2. Open any project folder in Jupyter Notebook.
3. Run the notebook to view analysis and results.

Each project folder contains:
- Jupyter notebook(s)
- Dataset or data source link
- Visualizations and findings
- Model performance summaries (if applicable)
